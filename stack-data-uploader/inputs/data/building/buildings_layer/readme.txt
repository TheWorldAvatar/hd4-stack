this was a dump from the buildings_layer from the Singapore-sea-level stack.
To generate the data, follow the instructions on https://github.com/cambridge-cares/TheWorldAvatar/tree/main/Deploy/stacks/Singapore-sea-level-rise to upload buildings data, then SQL dump the buildings_layer table

If it's too much hassle any polygon dataset will work, obviously the corresponding config needs to be modified to take in a vector dataset instead of an SQL file.
