Place vector files here. Polygons are expected to have the following properties:
1) formal_green (Boolean)
2) public_access (Boolean)
3) public_access_imputed_flag (Boolean)
4) year (integer)
5) formal_green_imputed_flag (Boolean)
6) public_access_imputed_flag (Boolean)
7) stable_track_flag (Boolean)

The name of these properties affect the sql script clip_raster.sql.

These polygons are later used to assign additional properties to ndvi_raster.
